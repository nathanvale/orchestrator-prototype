## How To Use
1. Start with the plan to understand scope and sequencing.
2. Use templates for new SKILL or pattern files.
3. Follow specs to keep the slot contract and generator consistent.
4. Use modes and voices as reference implementations.
5. Review examples for passdown mechanics.

## Contributing Checklist
1. Add or update templates in `templates/` when the contract changes.
2. Keep specs in `specs/` as the source of truth for structure and validation.
3. Add new modes in `modes/` and bind them to a voice in `voices/`.
4. Add or revise voice files in `voices/` with clear quote policy.
5. Update `examples/` when introducing new synthesis behavior.
